# Typewright trademarks

> Draft written from `docs/LICENSING.md` §1. The owner's own draft from the V1 pack replaces
> this file when it lands, and a lawyer reads it before v1.0.0.

"Typewright" and the isometric Doric-capital T icon identify the app made by Madhav Baliga
(A System of Cells). Name clearance is in progress. Neither code licence grants any right to
the name or the icon: FSL-1.1-ALv2 excludes trademarks explicitly, and Apache-2.0 §6 does the
same.

## Fine without asking

- Saying truthfully that your work is based on Typewright, or that it opens or writes
  Typewright projects.
- Redistributing unmodified official builds under their own name.
- Writing, teaching and talking about Typewright.

## Not without written permission

- Publishing a modified build, a fork, or a hosted service called "Typewright" or anything
  confusingly similar, or showing the icon on it.
- Using an application id that starts with `com.asoc.typewright`.
- Suggesting that the project or its author endorses your work.

## If you fork

Rename the app, replace the icon, and change the application id. Everything else the
licences allow stays allowed.
