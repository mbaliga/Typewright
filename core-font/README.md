# core-font

Pure Kotlin font data for Typewright: a binary sfnt/TrueType reader (`glyf`, composites, `cmap`, `hmtx`, `name`, `OS/2`, `post`) and a UFO 3 project reader and writer that round-trips everything it models losslessly — `fontinfo.plist` (names, version, vertical metrics including the hhea/typo/win sets, designer, manufacturer, licence, copyright, font-wide guidelines at any angle, and every other key kept verbatim), `lib.plist` (`public.glyphOrder`, names it lists without a glyph included, and every other key, `<data>` and `<date>` values included), glyphs with their unicodes, anchors and guidelines in both cubic (`curve`/`line`) and TrueType quadratic (`qcurve`, implied on-curve points kept implied) outlines, `groups.plist` kerning groups, `kerning.plist` kerning pairs, and `features.fea`'s raw OpenType feature text (read and written verbatim, never parsed or generated) — plus a bridge from a TrueType font to a UFO project that keeps its outlines and code points exactly; non-default layers, `images/` and `data/` are not modelled yet. Every file it writes must open in FontForge, Glyphs or RoboFont (the writer's output is checked against fontTools' validating `ufoLib` reader), real numbers are written as fontTools writes them and read correctly rounded so the same project gives the same bytes on the JVM and on Wasm, and it has no platform dependencies.
