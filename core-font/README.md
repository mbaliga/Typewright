# core-font

Pure Kotlin font data for Typewright: a binary sfnt/TrueType reader (`glyf`, composites, `cmap`, `hmtx`, `name`, `OS/2`, `post`) and a UFO 3 project reader and writer (`fontinfo.plist` including `xHeight`/`capHeight` and font-wide guidelines at any angle, per-glyph mark-attachment anchors and guidelines, `groups.plist` kerning groups, `kerning.plist` kerning pairs, and `features.fea`'s raw OpenType feature text — read and written verbatim, never parsed or generated), plus (later) non-default layers. Every file it writes must open in FontForge, Glyphs or RoboFont, and it has no platform dependencies.
